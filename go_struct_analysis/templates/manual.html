บทนำ (Introduction)

ยินดีต้อนรับสู่ GO Struct Analysis V.1.0.4.0 โปรแกรมสำหรับวิเคราะห์โครงสร้าง 2 มิติที่ทำงานร่วมกับ SketchUp พัฒนาโดย Phornjed Phongmanee

โปรแกรมนี้ถูกออกแบบมาให้ใช้งานง่าย รวดเร็ว และสามารถคำนวณพร้อมทั้งสร้างโมเดล 3 มิติกลับไปยังหน้าจอ SketchUp ได้ทันที เพียงแค่กรอกข้อมูลในตารางฝั่งซ้ายมือ ระบบจะวาดแปลนให้แบบ Real-time

ข้อแนะนำการใช้งาน:
ทุกโมดูลมีระบบสร้างไฟล์ Report เป็นไฟล์ HTML ให้คุณสามารถพริ้นต์ (Print) นำไปแนบรายการคำนวณได้ทันที

คู่มือการใช้งานคานต่อเนื่อง (GOBeam)

โมดูลนี้ใช้สำหรับคำนวณคานที่มีจุดรองรับหลายจุด (Continuous Beam) โดยสามารถกำหนดหน้าตัด ความยาวช่วง และน้ำหนักบรรทุกได้อย่างละเอียด เหมาะสำหรับคานบ้านและคานอาคารพานิชย์

1 การกำหนดหน้าตัดและความยาวช่วงคาน (Geometry)

ที่แท็บ Geometry & Section ทางซ้ายมือ ให้ระบุจำนวนช่องคาน (Spans) โปรแกรมจะสร้างตารางความยาวขึ้นมาโดยอัตโนมัติ คุณสามารถแก้ความยาว L (m) และเลือก Section (หน้าตัด) ให้แต่ละช่วงคานได้

2 การตั้งค่าจุดรองรับ (Supports)

ไปที่ตาราง Supports คุณสามารถเปลี่ยนพฤติกรรมของเสาแต่ละต้นได้ โดยมีให้เลือก 3 แบบ:

  • Pinned (พิน): รับแรงกดแต่ไม่รับโมเมนต์ (จุดรองรับทั่วไป)
  • Fixed (ยึดแน่น): รับแรงกดและรับโมเมนต์ (คานยื่นที่ต่อกับเสาใหญ่)
  • Free (อิสระ): ไม่มีเสารองรับ (ใช้สำหรับทำคานยื่น - Cantilever)

3 การใส่น้ำหนักบรรทุก (Loads)

ในแท็บ Loads คุณสามารถกดปุ่ม "+ Add Point Load" หรือ "+ Add Uniform Load" เพื่อใส่แรงกระทำ:

  • Point Load (แรงกระทำเป็นจุด): ระบุพิกัด X จากเสาต้นแรก และใส่ค่าน้ำหนัก P (kg) เช่น น้ำหนักผนังพาด หรือน้ำหนักจากเสาดั้ง
  • Uniform Load (แรงแผ่กระจาย): ระบุช่วง (Span) ที่ต้องการ และใส่ค่า w1 (จุดเริ่มต้น) และ w2 (จุดสิ้นสุด) ใช้สำหรับน้ำหนักพื้น หรือน้ำหนักผนังที่ก่อไปตามแนวยาว
การดูผลลัพธ์: กดปุ่ม Analyze Beam ระบบจะคำนวณและแสดงแผนภาพ Shear Force Diagram (SFD) และ Bending Moment Diagram (BMD) ทันที

คู่มือการใช้งานโครงข้อแข็ง (GOFrame)

โมดูลนี้ออกแบบมาเพื่อวิเคราะห์โครงข้อแข็ง (Rigid Frame) ที่มีการเชื่อมต่อแบบแข็งระหว่างเสากับคาน เหมาะสำหรับอาคารทรงสูง หรือโครงสร้างเหล็กรูปพรรณ (Portal Frame)

1 การใช้ Frame Generator (สร้างอัตโนมัติ)

โปรแกรมมีระบบ Frame Generator ทางซ้ายมือ เพื่อความรวดเร็วในการขึ้นรูป:

  1. เลือกรูปแบบจาก Dropdown เช่น Multi-story Frame (อาคารหลายชั้น) หรือ Gable Roof (โครงหลังคาจั่ว)
  2. กำหนดจำนวนชั้น (Stories) และจำนวนช่วงเสา (Bays)
  3. กำหนดความสูงและความกว้าง เมื่อพร้อมแล้วกดปุ่ม Generate Template โปรแกรมจะสร้างจุดและเส้นให้ทั้งหมด

2 การปรับแต่งโหนดและชิ้นส่วน (Nodes & Elements)

แม้จะใช้ Generator คุณก็ยังสามารถลบหรือเพิ่มชิ้นส่วนอิสระได้ โดยใช้แถบเครื่องมือบนจอภาพที่มีปุ่ม ➕ Node (วาดจุด) และ 📏 Member (ลากเส้นเชื่อมจุด) คุณยังสามารถไปแก้ตาราง Elements ด้านซ้ายเพื่อเปลี่ยนหน้าตัด (เช่น จาก I-Beam เป็น Pipe) ทีละชิ้นได้

3 การใส่แรงกระทำด้านข้าง (Wind Loads)

การวิเคราะห์ Frame มักต้องคำนึงถึงแรงลม (Wind Load) คุณสามารถไปที่ตาราง Loads เพิ่มแรง และกำหนด Direction เป็น `Local Y` เพื่อให้แรงกระทำตั้งฉากกับชิ้นส่วน หรือ `Global X` เพื่อให้แรงผลักไปทางแนวนอน

คู่มือการใช้งานโครงถัก (GOTruss)

โมดูลวิเคราะห์โครงถัก เน้นการส่งถ่ายแรงตามแนวแกน (Axial Force) เป็นหลัก โปรแกรมนี้ทำงานโดยตั้งสมมติฐานว่าทุกจุดต่อเป็นจุดหมุน (Pin-jointed)

1 เลือกรูปแบบโครงถักมาตรฐาน

เรามีรูปแบบมาตรฐานกว่า 10 รูปแบบให้เลือก เพียงแค่เปลี่ยน Truss Type โครงสร้างจะเปลี่ยนตามทันที

  • Pratt Truss: เหมาะสำหรับโครงหลังคาทั่วไปที่ชิ้นส่วนแนวทแยงรับแรงดึง
  • Howe Truss: ตรงข้ามกับ Pratt ชิ้นส่วนแนวทแยงรับแรงอัด
  • Warren Truss: ลักษณะรูปตัว W ต่อเนื่อง เหมาะสำหรับช่วงพาดปานกลาง

2 การปรับสัดส่วนโครงถัก (Geometry)

คุณสามารถระบุ:

  1. Panels (N): จำนวนช่อง ยิ่งมากช่อง โครงยิ่งมีความถี่สูง
  2. Panel Len (L): ความกว้างของแต่ละช่อง x จำนวนช่อง = ความกว้างรวม
  3. Ends H (He) / Mid H (Hm): ความสูงที่ขอบซ้ายขวา และความสูงที่จุดกึ่งกลาง (ยอดจั่ว)

3 การใส่น้ำหนัก (Equivalent Nodal Loads)

ในความเป็นจริง โครงถักจะรับแรงเฉพาะที่จุดต่อ (Nodes) แต่เพื่อความง่ายในการใช้งาน โปรแกรมอนุญาตให้คุณใส่ Uniform Load (kg/m) พาดบน Top Chord ได้เลย! โปรแกรมจะทำหน้าที่แปลงแรงแบบกระจายเหล่านั้น ให้กลายเป็นแรงลงที่จุดต่อ (Equivalent Nodal Loads) ให้อัตโนมัติ (สามารถสังเกตได้จากลูกศรใน Preview)

เครื่องมือจัดการหลายชิ้นส่วน (Bulk Edit / Multi-select)

เป็นฟีเจอร์ขั้นสูงที่ช่วยให้คุณประหยัดเวลาได้อย่างมหาศาล โดยเฉพาะเมื่อทำงานกับ Frame หรือ Truss ขนาดใหญ่ที่มีชิ้นส่วนเกิน 50 ชิ้นขึ้นไป

1 การเลือกชิ้นส่วน (Box Selection)

ที่แถบเครื่องมือวาดรูป (Canvas Tools) ให้กดเลือกโหมด 🖱️ Select จากนั้นนำเมาส์ไปลากเป็นกล่องสี่เหลี่ยมครอบชิ้นส่วนในหน้าจอ Preview ชิ้นส่วนที่โดนครอบจะถูกไฮไลท์สีฟ้า

2 การใช้งาน Selection Panel

เมื่อมีชิ้นส่วนถูกเลือก จะมีหน้าต่าง Selection Panel โปร่งแสงลอยขึ้นมาที่มุมขวาล่างของจอ ในนั้นจะมี 2 ความสามารถหลัก:

  1. Assign Section (เปลี่ยนหน้าตัด): เลือกหน้าตัดจาก Dropdown ปุ๊บ ชิ้นส่วนที่เลือกทั้งหมดจะเปลี่ยนหน้าตัดเป็นแบบเดียวกันทันที พร้อมอัพเดทตารางซ้ายมือให้ด้วย
  2. + Apply Load (ใส่แรง): กดเพื่อเปิด Popup สำหรับระบุค่าแรง (w1, w2, ทิศทาง, Load Case) ระบบจะนำค่าเหล่านี้ไปเขียนลงตาราง Load ให้กับทุกชิ้นส่วนที่เลือกไว้ สะดวกมากเวลาจะใส่แรงลมให้กับหลังคาทั้งแถบ!
การลบทีละมากๆ: คุณสามารถกดปุ่ม ❌ Delete บน Panel หรือกดปุ่ม Delete บนคีย์บอร์ด เพื่อลบชิ้นส่วนที่เลือกได้ทั้งหมดในคลิกเดียว
